ARS DJ — مرحله اول تحلیل آفلاین آهنگ

فایل: app/src/main/java/com/arsdj/library/AudioAnalysisEngine.kt

این موتور از FFmpeg برای تبدیل فایل به PCM مونو استفاده می‌کند، انرژی کلی صدا را
تخمین می‌زند و با روش هم‌بستگی پوش دامنه BPM تقریبی ارائه می‌دهد. این هنوز مدل
یادگیری عمیق نیست و کورس/دراپ یا کلید موسیقی را تشخیص نمی‌دهد. BPM ممکن است خطا
داشته باشد، مخصوصاً برای آهنگ‌های زنده، ریتم‌های پیچیده یا قطعات کم‌ضرب.

ورودی تابع analyze باید مسیر فایل محلی باشد، نه URI از نوع content://.
آن را روی ترد پس‌زمینه اجرا کنید تا رابط کاربری قفل نشود.

روش افزودن:
1) فایل را در مسیر بالا در GitHub ایجاد کنید.
2) محتوای فایل Kotlin را از ZIP کپی کنید و Commit بزنید.
3) GitHub Actions را بررسی کنید.

این مرحله فقط موتور تحلیل را اضافه می‌کند؛ هنوز به دکمه‌ها و صفحه AI متصل نشده است.
مرحله بعد، اتصال آن به MainActivity و نمایش نتیجه‌ها در رابط کاربری است.
